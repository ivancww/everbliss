# OALA assessment — source and limitations

The SWD OALA page https://www.swd.gov.hk/oala/ and FAQ https://www.swd.gov.hk/oala/doc/OALAWebsiteFAQ_Income_Asset_TC.pdf were reviewed on 2026-10-27. Effective 2026-02-01, the monthly income / asset limits are HK$10,900 / HK$415,000 for single persons and HK$16,680 / HK$630,000 for couples. The current allowance is HK$4,345 per eligible person per month. The SWD page explains qualifying cohabitation, applicable owner-occupied property and insurance cash value exclusions, family support, annuity premiums, fixed payments and surrender proceeds.

EverBliss's specific classification and treatment of non-guaranteed payments have not been independently verified with SWD. The after-arrangement estimate is explicitly conditional: it assumes a qualifying premium funded from assessable assets and assumes the displayed payout is assessable. It is not a statement of eligibility, and the financial limits do not cover all eligibility conditions. Amounts exceeding current assets produce no after result. Monthly cashflow uses the existing product outcome schedule and the same FX rate as the journey.

AVA Platform's inspected launcher performs normal URL navigation with an avaEntry parameter. Such a new load starts at Home while preserving saved customer values. A future host which merely re-shows a mounted iframe or cached SPA without a new URL navigation does not provide an observable new-entry signal to the app. Supporting that lifecycle requires AVA Platform to send an authenticated, origin-checked dedicated app-entry message (including an entry instance identifier) on each re-entry; EverBliss must handle that signal without interpreting ordinary visibility or app switching as a new entry. This host dependency has not been implemented or live-tested here.

## v0.4.2 presentation

The four independent SWD topics remain collapsed by default. The official limits and allowance were rechecked against the SWD OALA page on 2026-10-27. A financial-limits pass can display a conditional illustration using the existing schedule payout plus one eligible person's allowance; it is not a prediction of approval. The couple assessment does not assume a second eligible recipient. Amount inputs are formatted during editing while the numeric values, or null for incomplete/invalid entries, are stored.
