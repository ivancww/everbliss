# EverBliss v0.4.1 journey UX

The liquidity page offers amount or years of living expenses. A blank years value or the Unknown checkbox leaves the reserve and available allocation undetermined. Selecting Unknown preserves the draft years and opens a dismissible explanation. Legacy month values are converted to years by dividing by 12; legacy Unknown remains unknown. Amount-based state is unchanged.

The result page selects an actual schedule row by policy year and attained age. Cumulative displayed income sums the existing rounded annual displayed income for each scheduled year through that row, including each year's guaranteed and applicable non-guaranteed income once. Deferred years without payments remain zero; values are converted for display using the existing FX formatter. It does not add premiums, surrender values or death benefits. The year-8 information and non-guarantee disclosure remain outside the blue card.

Summary now records its journey step and its Back action explicitly returns to the result page, including when restoring an older unsynchronised summary state. Customer inputs and selected result year remain in local state. Summary no longer contains the restart button or bottom disclosure bar. User presentation overrides remain separate from Official data; Admin authentication is unchanged.

The release contract remains independently versioned from AVA Platform and uses the existing build-ID and service-worker update mechanism. Mobile and iPad live interaction should be verified on real devices; no production deployment or Gemini review is claimed here.
