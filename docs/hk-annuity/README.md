# HKMC annuity data: staging only

The accompanying import-ready CSV transcribes the HKMC reference example for a HK$1,000,000 single premium, ages 60–85, male and female. Source: https://www.hkmca.hk/eng/files/LAS60_Example_of_Guaranteed_Monthly_Annuity_Payment_Table_Eng.pdf (accessed 2026-10-27). The document gives no effective date and says the figures are for reference only. This is not a current customer quotation, verified complete premium schedule, or authority to scale or extrapolate it. No data is loaded into the application.

The existing EverBliss GAS adapter supplies EverBliss records, not an approved HKMC feed. No Google Sheet has been created or connected and no production endpoint was changed. Before enabling values, obtain the owner-supplied official HKMC documents, verify current rates and eligibility, source effective dates and permitted premium scaling/rounding, and establish an approved read-only endpoint with validated versioned data and appropriate cache semantics. Prepare separate rates, rules, values and sources tabs. Missing surrender and death data must remain unavailable. Verify payment timing before summing benefits and previously paid income. The financial comparison must not imply government values are present until these gates are complete.
